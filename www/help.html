📱 App အကြောင်း

Machine Hub User က arcade စက်တွေရဲ့ machine code ကို offline မှာ ရှာဖွေဖို့ ဖန်တီးထားတဲ့ app ဖြစ်ပါတယ်။

  • ✅ Internet မလိုဘူး — 100% offline
  • ✅ Server မလိုဘူး — data ဖုန်းထဲပဲ
  • ✅ Fast — 50ms အတွင်း ရလဒ်
  • ✅ Private — data ကို ဘယ်ကိုမှ မပို့ဘူး
  • ✅ Free — အမြဲ
💡 ဘယ်သူတွေအတွက်လဲ?
Arcade technician, floor staff, စက်ပြင်သူများ

📥 Excel Import လုပ်နည်း

App ကို ပထမဆုံး ဖွင့်တာနဲ့ Excel file import လုပ်ဖို့ လိုပါတယ်။

1
Excel File ရယူပါ
Admin / မန်နေဂျာ ဆီက .xlsx / .csv file ရယူပါ
2
Home → "Excel File ရွေးပါ"
File picker ပေါ်လာမယ်
3
File ရွေးပါ
Preview ပေါ်လာမယ် — ဘယ်နှစ်ခု import လုပ်မလဲ ပြ
4
"Import" နှိပ်ပါ
Progress bar ပြီး — data save ဖြစ်မယ်
⚠️ သတိထားပါ:
File အသစ် import လုပ်ရင် အဟောင်း data အားလုံး ပျက်သွားမယ်။ Confirm dialog ပေါ်ရင် "Replace" နှိပ်ပါ။
📄 Excel Format:
machine_code (required)
machine_name (optional)
shop_code / location (optional)
description (optional)

🔍 ရှာဖွေနည်း

Home page ရဲ့ search box မှာ machine code သို့ name ရိုက်ပါ။

💡 ရှာဖွေနည်း ဥပမာ:
Dream — name partial
R_MEDAL — code partial
M_SLOT_001 — exact code
Aladdin — name exact
  • ✅ Partial match — "Dre" ရိုက်ရင် "Dream" တွေ့
  • ✅ Case-insensitive — "DREAM" = "dream"
  • ✅ Auto-search — 150ms အတွင်း ရလဒ်
  • ✅ No internet needed
🎯 Tips:
• Code တစ်ခုလုံး မရှိရင် — partial ရိုက်
• Name ပါရင် — name ရိုက်
• ရလဒ် မတွေ့ရင် — အခြား keyword စမ်း

❓ FAQ

Internet မရှိရင် သုံးလို့ ရလား?

ရပါတယ်။ 100% offline ဖြစ်လို့ internet မလိုဘူး။ Excel import တစ်ခါ လုပ်ပြီးရင် — always offline အလုပ်လုပ်တယ်။

Server / Cloud လိုလား?

မလိုဘူး။ Data က ဖုန်းထဲ (IndexedDB) ပဲ သိမ်းတယ်။ Cloud ကို ဘယ်တော့မှ မချိတ် — privacy 100%။

Excel file ဘယ်လို format လဲ?

machine_code column မဖြစ်မနေ ပါရမယ်။ ကျန်တာ optional: machine_name, shop_code/location, description။

📄 Format Help ကြည့်ပါ
Excel import ၂ ခါ လုပ်ရင် ဘာဖြစ်မလဲ?

အဟောင်း data အားလုံး ပျက်သွားမယ် — အသစ် data ပဲ ကျန်မယ်။ Confirm dialog ပေါ်ရင် "Replace" နှိပ်ပါ။

✅ 5 sec Undo: Import ပြီးရင် toast မှာ UNDO button နှိပ်ရင် ပြန်ရနိုင်တယ်

Machine data ဘယ်လောက်ထိ ထည့်လို့ရလဲ?

အကန့်အသတ် မရှိဘူး။ ၁၀၀၀၀+ rows ထည့်လို့ရတယ်။ IndexedDB က ဖုန်း storage ပေါ်မှာ မူတည်တယ်။

Copy လုပ်ရင် "Copied" မပြဘူး?

Clipboard permission စစ်ပါ။ Settings → Apps → Machine Hub → Permissions → Clipboard allow။

App နှေးလာရင် ဘယ်လိုလုပ်မလဲ?

1. Settings → Clear Search History
2. App close → open
3. မရင် — App reinstall (data ပျက်မယ်၊ Excel ပြန် import လုပ်ရမယ်)

Data backup လုပ်လို့ ရလား?

Excel file ကို သိမ်းထားပါ။ Import လုပ်ခဲ့တဲ့ file က backup အဖြစ် ပြန်လုပ်လို့ရတယ်။

APK ကို update လုပ်ဖို့ လိုလား?

မလိုဘူး — data update က Excel file နဲ့ပဲ လုပ်တယ်။ APK ကို update လုပ်ဖို့ လိုတာ — feature အသစ် ထည့်ရင်သာ။

Machine Hub (Admin) နဲ့ ဆိုင်လား?

Machine Hub User က — offline-only user app။ Machine Hub Admin က — separate system (server + cloud)။ ၂ ခု မတူညီဘူး။ ဒီ app က admin မပါ — user အတွက်ပဲ။
