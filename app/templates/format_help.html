Excel Format လမ်းညွှန်

Machine data ကို Excel file (.xlsx or .csv) နဲ့ ထည့်ပါ

Sample File ရယူပါ

Columns

machine_code Required
Machine အမှတ်အသား — English, numbers, underscore (_) ရပါတယ်
Example: M_SLOT_001, R_MEDAL_AVENGERS_001
machine_name Optional
Machine နာမည် — မထည့်ရင် code ကို name အဖြစ် သုံးမယ်
Example: Dream Castle, Aladdin
shop_code Optional
Shop / Location — မထည့်ရင် "location" column ကို ရှာမယ်
Example: A3, A4, A5
description Optional
အပိုအချက်အလက်
Example: Slot machine, Racing game

Excel နမူနာ

machine_code machine_name shop_code description
M_SLOT_001 Dream Castle A3 Slot
R_MEDAL_001 Avengers A4 Medal
P_CLAW_001 Epic Mini A3 Claw

Tips

✅
Header — case-insensitive
"Machine Code" သို့ "machine_code" — ၂ မျိုးလုံး ရပါတယ်
✅
Duplicate — skip
Same code ၂ ခါ ရှိရင် ပထမ တစ်ခုပဲ ယူမယ်
✅
Empty rows — skip
machine_code empty ဖြစ်ရင် ကျော်လိုက်မယ်
⚠️
Import — replace mode
File အသစ် ထည့်ရင် အဟောင်း data အားလုံး ပျက်မယ်
